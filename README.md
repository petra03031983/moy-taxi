# Мой Такси — taxi-only source snapshot

Это отдельная ветка, подготовленная для передачи именно платформы такси. Из текущего дерева удалены файлы «Астана Гид», дорожные API и Android-сканер. Основная ветка main не изменена.

## Состав
- единый веб/PWA-проект с пассажирской и водительской ролями
- интерфейс на казахском, русском и английском
- кабинет владельца
- заказы и предложения цены водителя
- тарифные классы, баланс/лицевой счёт и учёт комиссии
- Supabase Edge Functions: moy-taxi-api и moy-taxi-api-feed
- SQL-миграции для taxi core и связанных функций

## Важно перед запуском
- Это исходный пакет для технической передачи, а не подтверждение, что его можно установить на пустую базу без дополнительных действий. Сначала проверьте миграции на отдельном пустом Supabase-проекте.
- Не публикуйте сервисные ключи или пароли в исходниках, README, задачах GitHub либо демонстрационных скриншотах.
- В веб-приложении нужны NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_ANON_KEY. Это клиентские настройки; значение service_role должно оставаться только в серверных секретах Supabase.
- Для API такси нужно развернуть обе функции moy-taxi-api и moy-taxi-api-feed. Ключ 2GIS настраивается отдельно в панели владельца/настройках проекта; сам сервис 2GIS остаётся внешней зависимостью.
- Способ оплаты Kaspi — выбор/инструкция для перевода, а не автоматический банковский эквайринг.
- Android-проект такси в этой ветке не включён: удалённый Android-проект относился к сканеру «Астана Гид». Текущая поставка — веб/PWA.
- Перед передачей покупателю нужно сменить/пересоздать ключи и учётные данные, создать инфраструктуру покупателя и договориться о том, какие тестовые данные переносятся.

## Локальный запуск веб-клиента
```bash
npm install
npm run dev
```

Для production-запуска нужно развернуть проект из доверенной приватной копии в аккаунт покупателя и отдельно развернуть обе Supabase Edge Functions. Не подключайте эту ветку к текущему production-домену до завершения проверки.

## Для продавца
Не передавать покупателю все файлы и данные общей ветки/repository. Для чистой передачи нужен отдельный приватный repository или архив текущего дерева, а затем независимая проверка деплоя и базы.

## Ограничение конфиденциальности
Эта ветка удаляет картографические файлы из текущего дерева, но находится в том же GitHub-репозитории. История репозитория по-прежнему содержит старые версии, в которых были файлы «Астана Гид» и сканера. Не передавайте покупателю ссылку на весь репозиторий как на закрытый пакет. Для передачи понадобится архив только текущего дерева этой ветки или отдельный приватный репозиторий.
