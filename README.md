# Мой Такси

Next.js-приложение с главным входом водителя и отдельной клиентской страницей, доступной по персональному QR-коду.

## Как работает

- Главная страница `/` — вход водителя и регистрация по имени, телефону и паролю.
- Панель водителя показывает его QR-код, новые и текущие заказы, историю, статус на линии и профиль.
- Клиентская страница открывается по адресу `/c/КОД_ВОДИТЕЛЯ`; QR-код содержит именно эту ссылку.
- Заказы сохраняются за водителем, чей код был отсканирован.
- Панель водителя открывается также по адресу `/driver` и перенаправляет на главный вход.

## Запуск

```bash
npm install
npm run dev
```

## Переменные окружения

- `NEXT_PUBLIC_SUPABASE_URL` — URL проекта Supabase.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — публичный anon JWT для вызова Edge Function.

API исходники находятся в `supabase/functions/moy-taxi-api/index.ts`, миграции БД — в `supabase/migrations/`.

Vercel автоматически собирает проект из ветки `main` репозитория GitHub.
