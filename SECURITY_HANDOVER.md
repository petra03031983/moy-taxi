# Мой Такси — безопасность перед продажей

## Принцип

Покупателю не передаются действующие доступы продавца. Исходный код и новая инфраструктура должны быть разделены.

## Перед передачей

- создать новый Supabase-проект покупателя;
- создать новый Vercel-проект/аккаунт покупателя;
- создать новый ключ 2GIS покупателя, если 2GIS остаётся на первом этапе;
- заменить все environment variables на credentials покупателя;
- не переносить действующие service_role keys;
- сменить пароль владельца демонстрационной/тестовой среды;
- удалить тестовые телефонные номера и персональные данные из демонстрационной базы;
- не передавать историю Git общего репозитория как часть сделки;
- передавать только отдельный архив taxi-only дерева.

## Защитный код

Защитный код для первичной передачи должен храниться **вне репозитория и отдельно от исходного архива**. Его нельзя помещать в README, JavaScript, SQL, GitHub Issues или публичные скриншоты.

Если покупателю передаётся архив через защищённый канал, код сообщается отдельным каналом. После первого входа пароль владельца меняется.

## Что проверить перед окончательной передачей

1. Пассажир может создать заказ.
2. Водитель видит заказ и может принять его.
3. Водитель может предложить другую цену.
4. Пассажир может принять/отклонить предложение.
5. Заказ не исчезает из ленты при отказе одного водителя.
6. Завершённая поездка появляется в кабинете владельца.
7. Комиссия рассчитывается согласно установленному проценту.
8. Баланс/лицевой счёт водителя учитывается при работе с комиссией.
9. Тарифы сохраняются после изменения.
10. Роли пассажира и водителя изолированы.
11. Владелец видит водителей, заказы и финансовые показатели.
12. После замены credentials покупателя старые credentials продавца нигде не используются.

## Важное замечание

Этот документ является чек-листом передачи. Он не заменяет юридический договор купли-продажи программного обеспечения и не является гарантией соответствия местному законодательству.
